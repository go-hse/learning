Das Wichtigste in Kürze

Der Lerntrainer speichert deine Antworten, Punkte und Einstellungen ausschließlich im Browser auf deinem Gerät. Es gibt keine Benutzerkonten, keine Cookies, kein Tracking und keine Inhalte von fremden Servern. Beim Aufruf der Seite verarbeitet allerdings der Hoster GitHub technisch bedingt deine IP-Adresse.

Beim Aufruf überträgt dein Browser technisch notwendig Daten an die Server von GitHub, insbesondere deine IP-Adresse, Datum und Uhrzeit des Abrufs, die aufgerufene Datei sowie Angaben zu Browser und Betriebssystem. 2. Speicherung auf deinem Gerät

Damit der Lerntrainer funktioniert, speichert er folgende Daten im lokalen Speicher deines Browsers (LocalStorage): deine Antworten mit Zeitpunkt und Ergebnis, Punkte, Tagesziel und Einstellungen sowie den Stand einer laufenden Übungsrunde. Zusätzlich legt der Browser die Dateien der App und den Fragenkatalog in einem Zwischenspeicher ab, damit die App auch offline läuft.

Diese Daten verlassen dein Gerät nicht und werden nicht an den Verantwortlichen oder an Dritte übertragen. Die Speicherung ist für den von dir gewünschten Dienst unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG); eine Einwilligung ist dafür nicht nötig.

Du kannst die Daten jederzeit löschen: in den Einstellungen über „Lernstand löschen“ oder über die Browsereinstellungen („Websitedaten löschen“).

3. Export und Import

Mit „Lernstand exportieren“ erzeugt der Browser eine Datei mit deinen Lerndaten. Die Datei wird nur auf deinem Gerät gespeichert bzw. dorthin weitergegeben, wohin du sie selbst schickst. Beim Import wird die Datei ausschließlich lokal im Browser gelesen.

4. Keine Cookies, kein Tracking

Der Lerntrainer setzt keine Cookies, verwendet keine Analyse- oder Tracking-Werkzeuge und lädt keine Inhalte von fremden Servern (z. B. Schriftarten oder Skripte).

Da der Verantwortliche selbst keine Daten von dir speichert, betreffen diese Rechte vor allem die Verarbeitung durch GitHub beim Abruf der Seite.
