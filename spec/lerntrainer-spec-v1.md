# Idee: Lern-Karten-SPA
- Unterschiedliche Fragetypen
    - Multiple Choice
    - Erläutere Begriff
    - 3 Schwierigkeitsgrade

- Fragen-Katalog als JSON mit gehostet oder Möglichkeit zum Upload
- unterschiedliche Kapitel/Schwierigkeitsgrade
- Streak/History-Exportiertbar
    - Ziel: jeden Tag 20 Fragen bearbeiten
- Bei Multiple Choice:
    - Bonus-Punkte: richtige Antwort beim 1. Mal: 10 Pkt; beim 2. Mal 8, beim 3. Mal 6 ... 0
    - Malus-Punkte: falsche Antwort beim 1. Mal: 0 Pkt, beim 2. Mal -1, beim 3. Mal -2, ... -5

# Ablauf
- Student wählt Fach
- Wahl eine Kapitels
    - Fragen in aufsteigender Schwierigkeit
- Oder: Mix-Modus alle bereits - ggfs. falsch - beantworteten Fragen in Mischung
    - Dabei: falsch beantwortete Fragen werden häufiger eingespielt; Widerholung nach 3-5 anderen Fragen
- Evtl. gibt es Frage-Typen, wo der Lernende selbst entscheidet, ob er die Lösung wusste -> keine Punkte

# Statistiken:
- welche Frage wurde besonders häufig falsch beantwortet
- Streak: wieviele Tage in Folge mit erreichen des Tagesziels (20 Fragen pro Tag, gerne mehr)
- wieviele richtige Antworten hintereinander - bei einer falschen Antwort zurück auf 0


# Technlogie
- Vanilla HTML5, CSS, JavaScript
- Gehostet auf Github-Pages
- alles im LocalStorage-Gespeichert; Möglichkeit eigene Historie zu exportieren und auf anderem Gerät zu importieren.
